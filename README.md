# Windows TI - Practical Scripting Toolkit for IT Support

This repository is a curated collection of practical scripts and command-line tools designed for IT support professionals in enterprise environments. It covers key areas including:

- ✅ PowerShell automation for disk checks, backups, and service monitoring  
- ✅ CMD/Batch commands for diagnostics, system management, and user administration  
- ✅ Git command reference for source control and collaboration

These tools are especially useful for environments with diverse user profiles—developers, analysts, administrative staff, and remote users.

## 📂 Contents

- **PowerShell Scripts**: Automate tasks like disk usage audits, user backups, remote reboots, and software inventory exports.
- **Batch Commands**: Useful for quick diagnostics like `ipconfig`, `tracert`, `gpupdate`, and system utilities like `powercfg`.
- **Git Commands**: Basic to advanced Git usage including branching, merging, ignoring files, and repository setup.

## 💼 Use Case

Ideal for system administrators and IT support engineers managing mixed Windows environments who need to respond efficiently with repeatable, automated solutions.
Feel free to contribute, fork, or adapt for your own organization's needs.
